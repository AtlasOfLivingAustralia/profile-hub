# Profiles Angular (Grails embeds)

This workspace is a shared library of Angular page-root components injected into Grails GSP views — not a monolithic SPA.

## How it works

1. Grails renders a host tag on a page, e.g. `<app-page-a-root></app-page-a-root>`.
2. The Angular bundle (`main.js`) loads as an ES module.
3. [`src/main.ts`](src/main.ts) calls `createApplication()`, then bootstraps only the roots whose host tags exist on the page.
4. Shared services (e.g. [`DataService`](src/app/services/data.service.ts)) are singletons on that shared injector.

## Local development (`ng serve`)

```bash
pnpm install
pnpm start
```

Open `http://localhost:4200/`. [`src/index.html`](src/index.html) includes both demo host tags; comment one out to test selective bootstrap.

## Build for Grails

```bash
pnpm run build:grails
```

Or from the repo root (installs deps, builds, copies into asset-pipeline):

```bash
./gradlew copyAngularAssets
```

Output lands in `grails-app/assets/javascripts/profiles-angular/` (`main.js`, `styles.css`). That directory is gitignored and regenerated by Gradle/`assetCompile`/`bootJar`.

## Demo Grails pages

After assets are built and the app is running:

- `/angular-demo/page-a` — hosts `<app-page-a-root>`
- `/angular-demo/page-b` — hosts `<app-page-b-root>`

Reuse the load pattern from [`grails-app/views/angularDemo/_profilesAngular.gsp`](../../grails-app/views/angularDemo/_profilesAngular.gsp) on any GSP:

```gsp
<link rel="stylesheet" href="${asset.assetPath(src: 'profiles-angular/styles.css')}"/>
<script type="module" src="${asset.assetPath(src: 'profiles-angular/main.js')}"></script>
<app-page-a-root></app-page-a-root>
```

## Adding a new page root

1. Generate a standalone component under `src/app/components/`.
2. Register it in `src/main.ts` (query its selector, then `appRef.bootstrap(...)`).
3. Place the custom element in the target GSP and include `_profilesAngular` (or equivalent script tags).
